# Seamless Ores: Matrix

A companion to [Seamless Ores](https://modrinth.com/mod/seamless-ores). When a modded stone generates
around ore, the ore keeps a plain stone or deepslate look and stands out as a square of the wrong rock.
This mod gives that ore the stone it actually sits in.

- The same ore generates in the same places and in the same amounts. Only its look changes.
- Mining, drops, Fortune, Silk Touch and experience match the vanilla ore.
- Every overlay is hand drawn and shared with Seamless Ores, so resource packs that restyle one
  restyle both. The stone itself is drawn by the mod that adds it; nothing of it ships here.
- A variant only exists when its stone's mod is installed.

## Supported stones (Minecraft 26.3)

| Stone | Mod | Loaders | Ores |
|---|---|---|---|
| Limestone | Blockus | Fabric | coal, iron, copper, gold, redstone, emerald, lapis, diamond |
| Marble | Blockus | Fabric | coal, iron, copper, gold, redstone, emerald, lapis, diamond |
| Bluestone | Blockus | Fabric | coal, iron, copper, gold, redstone, emerald, lapis, diamond |
| Viridite | Blockus | Fabric | iron, gold, redstone, lapis, diamond |
| Gabbro | Wilder Wild | Fabric, NeoForge | coal, iron, copper, gold, redstone, lapis, diamond |

Block ids are `seamlessoresmatrix:<mod>_<stone>_<ore>_ore`, for example
`seamlessoresmatrix:blockus_limestone_iron_ore`.
